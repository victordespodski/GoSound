# Предварително проучване

Работна основа на база първоначалното проучване за GoSound от 13.11.2026. При пренасяне в училищната документация източниците се оформят и преномерират по училищните правила.

| Решение | Наблюдавани характеристики | Извод за GoSound |
|---|---|---|
| Spotify for Creators | Глави и аналитика за автори [1,2] | Ръчни глави след надежден плеър; статистика само след завършено ядро |
| Apple Podcasts | RSS изисквания, стабилни идентификатори и byte-range аудио [3] | Отделни Podcast/Episode; HTTP range при бъдещия audio endpoint |

Изборът е ограничен учебен продукт с български интерфейс и запазване на прогреса. Не е проведено представително пазарно изследване; не се твърди уникалност на идеята или свободна търговска марка.

MVC/Razor използва знанията по C# и удовлетворява посочения училищен технологичен обхват. EF Core моделира релациите, а SQL Server отговаря на конкретния критерий. Един web проект с папки Models/Data/Controllers/Views е начална организация за по-лесно отваряне; отделни слоеве могат да се извлекат при развитие. Това не е вече реализирана многопроектна архитектура.

[1] https://support.spotify.com/us/creators/article/episode-chapters/
[2] https://support.spotify.com/us/creators/article/overview-analytics/
[3] https://podcasters.apple.com/support/823-podcast-requirements
[4] https://learn.microsoft.com/en-us/aspnet/core/mvc/overview
[5] https://learn.microsoft.com/en-us/ef/core/managing-schemas/migrations/

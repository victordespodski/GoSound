# Етап 1 — кратък текст за Classroom

GitHub: https://github.com/victordespodski/GoSound

Техническа документация: https://github.com/victordespodski/GoSound/blob/main/docs/Stage1.md

Оформена документация: приложи отделно Word/PDF файла или личен споделен линк с достъп на консултанта. Не публикувай документа с лични полета в публичното хранилище.

GoSound е уеб платформа за подкасти и аудио предавания. Планирани са регистрация и вход, каталог с търсене и категории, авторско управление на предавания и епизоди, плеър, следване, запазен прогрес и административна модерация. Допълнително се предвиждат ръчни глави и лични отметки. Технологии: ASP.NET Core MVC, Razor, EF Core и MS SQL Server.

Началният код включва визия, навигация, каталог, категории, модел, EF миграция и SQL схема. Проверките са описани в docs/Checks.md и GitHub Actions.

Остава административно: потвърдени три имена, клас и консултант; прилагане на подписаното задание; проверен достъп на консултанта до документацията; локален старт и създаване на базата на компютъра за демонстрация.

# Технологии
.NET 8 SDK; ASP.NET Core MVC и Razor; EF Core SQL Server 8.0.34; ASP.NET Core Identity EF 8.0.34; SQL Server (избери поддържана локална инсталация); CSS; GitHub Actions. NuGet пакетите са фиксирани към базова съвместима версия. Преди предаване проверете и актуализирайте пакетите в една съвместима основна версия и изпълнете build/security checks. Проверено компилиране с SDK за .NET 8.

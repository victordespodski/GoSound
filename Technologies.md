# Технологии
.NET 10 SDK; ASP.NET Core MVC и Razor; EF Core SQL Server 10.0.15; ASP.NET Core Identity EF 10.0.15; SQL Server (избери поддържана локална инсталация); CSS; GitHub Actions. NuGet пакетите са фиксирани към базова съвместима версия. Преди предаване проверете и актуализирайте пакетите в една съвместима основна версия и изпълнете build/security checks. Проверено компилиране с SDK 10.0.100.
